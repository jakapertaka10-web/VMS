# NUVION – Smart Multifunctional Shoe Rack

Website interaktif untuk produk NUVION (PPTSI II).

## Struktur
- `index.html` – halaman utama
- `style.css` – tampilan
- `app.js` – simulasi interaktif, kartu spesifikasi, galeri
- `assets/` – foto produk dan logo

## Deploy ke GitHub Pages
1. Buat repository baru di GitHub (misalnya `nuvion`).
2. Upload semua file dan folder ini ke repository (pastikan `index.html` ada di root).
3. Buka **Settings > Pages**.
4. Di **Build and deployment**, pilih **Deploy from a branch**, branch `main`, folder `/ (root)`, lalu **Save**.
5. Tunggu 1-2 menit. Situs tampil di `https://USERNAME.github.io/nuvion/`.
